# Admin Bar Experiment

An experimental WordPress plugin that tweaks the admin bar:

- **Inert WordPress logo** outside the block editors: no link, no submenu, no hover state.
- **Admin menu overlay** in the post editor and Site Editor: hover, focus or click the WordPress logo to reveal the main admin navigation over the editor.
- **Help menu** (question-mark icon, top right) with Documentation, Learn WordPress, Support and Feedback.
- **About WordPress** is reached by clicking the version number in the admin footer.

## Try it

[![Try it in WordPress Playground](https://img.shields.io/badge/Try%20it%20in-WordPress%20Playground-3858e9?logo=wordpress)](https://playground.wordpress.net/?blueprint-url=https://raw.githubusercontent.com/jameskoster/admin-bar-experiment/HEAD/blueprint.json)

Opens a temporary WordPress site in your browser with the plugin active, straight into the post editor. Nothing is installed anywhere.

## Requirements

WordPress 7.0+ (the admin bar must be visible in the block editors). The overlay applies at viewport widths of 782px and above.
